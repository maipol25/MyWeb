Spotify Top Music Analysis

分析 73 國 170 萬行 Spotify 數據：NLP 情感、國家偏好地圖與 XGBoost 熱門預測（課程最高分組）。

Kaggle BERT XGBoost GeoPandas
查看詳情

在 my little project 目錄下的 flexible-skill-agent（Phase 0）是一個 fictional 課程助教原型，服務合成課程 IS9999 Enterprise AI Systems。我實現從 ingest 建索引到 Streamlit 對話的完整 RAG 流程，並透過 skills/mode_ta.json 限制僅依上下文作答並加入簡短的 prompt-injection 防護。

500/50 分塊大小 / 重疊
120k 全檔模式字元上限
k=8 相似度檢索
2 全檔來源檔上限

技術棧

LLM：OpenRouter（預設），可選 Ollama 或 Gemini。
Embeddings：Chroma 本地嵌入。
UI：Streamlit。
Vector store：Chroma（chroma_db/）。

檢索與功能

側邊欄 Full file mode 預設開啟：先以 k=8 相似度搜尋，選最多 兩個來源檔，再載入該檔在 Chroma 中的全部 chunks；上下文上限 120,000 字元。關閉後改為經典 top-8 chunk 檢索。
ingest.py 建索引；core/chat_log.py 支援本地 JSONL 對話日誌。

專案結構（摘錄）

app.py · ingest.py · core/（chat_log, llm_provider, vector_store）· data/ · skills/mode_ta.json

這是一個大學課程的大數據分析項目，由我與另一位同學兩個人合力完成，並最終得到此課程所有組別中的最高分數。此項目通過分析 Spotify 全球 73 個國家的 170 萬行音樂數據，揭示音樂成功的關鍵因素。數據來源： Kaggle

第一部分：數據收集與準備

從 Kaggle 獲取 Spotify 每日更新的全球流行音樂 dataset，包含 25 列特徵和 170 萬行記錄。進行了數據清理、去重和特徵工程，為後續分析奠定基礎。

第二部分：分析方向

NLP 情感分析

（歌詞情感分析詞雲）

篩選熱門歌曲，使用 Genius API 獲取歌詞，應用 BERT 模型進行情感分析。發現具有明顯情感（高度正面或負面）的歌詞更易流行。

國家偏好分析

（對音樂響度的偏好）

（對音樂節奏感的偏好）

使用 Python 與 matplotlib、geopandas 繪製全球 loudness 與 tempo 偏好地圖，揭示地區文化差異與 danceability、energy 等特徵的綜合洞察。

機器學習建模

（簡單流程示意圖）

開發 XGBoost 分類模型預測歌曲能否進入熱門榜，依據 tempo、duration、key、valence 等音頻特徵，準確率達 72.56%，優於基準模型。

第三部分：項目總結

項目揭示情感張揚的歌詞、顯著的地區偏好差異，以及可用的熱門預測模型；並將洞察轉化為個性化推薦、本地化營銷與創作指導等商業價值。
