Flexible Skill Agent 是我在本機探索的靈活學習助理（目前 Phase 2 — 面具模式）：同一套流程可把教材或筆記變成專用對話助理，而不必為每門課手工重寫提示詞。開發方式以 vibe coding 為主——在 Cursor 裡邊描述需求邊改程式，快速試錯。

① 上傳資料
② 本地索引
③ 生成面具技能
④ RAG 對話

這是什麼

像把一疊講義丟進「會自己讀書的助教機器」——它先整理內容、自動寫好規則（技能 skill＋系統提示詞），再戴著面具 mask（一組材料對應的設定檔）只根據那份資料回答。RAG（檢索增強生成）可先比喻成：問問題前先在筆記裡翻相關段落，再請模型依段落作答，減少憑空編造。

怎麼運作

  1. 在 Streamlit 介面上傳 PDF 或 Markdown，檔案存到該面具的資料夾。
  2. ingest 流程把文件切成片段，用Chroma 在本機建立向量索引（嵌入預設本地，不必為建索引另外付 API）。
  3. mask_factory 抽樣文件內容，經LLM 起草 skills/masks/{id}.json：角色、答題規則、引用檔名、簡短防注入拒絕句。
  4. 確認技能後進入聊天：每個問題先做相似度搜尋，把命中片段當 RETRIEVED CONTEXT 餵給模型，並標出來源檔名。
  5. 側欄可切換 Full file mode：先找最相關的 1–2 份檔，再把該檔在索引中的片段整批送入（有字數上限），適合需要通讀單一講義的問題；關閉則用經典 top‑k 片段模式。
  6. 換一套教材＝換面具；內建預設 course_ta 面具保留示範課程助理行為。

相關技術

用 Python 把小應用、文件索引與雲端／本機大模型接在一起；聊天預設走 API，索引與嵌入多在本機完成。

  • Python — 主程式、面具註冊、上傳管線與對話邏輯。
  • Streamlit — 瀏覽器裡的操作介面（上傳 → 確認技能 → 聊天）。
  • LangChain — 文件載入、文字切割（langchain-text-splitters）與訊息格式。
  • langchain-openai — 以 OpenAI 相容介面連到 OpenRouter（預設聊天後端）。
  • OpenRouter — 雲端 LLM API 閘道；在 .env 換模型名稱即可。
  • Ollama / Gemini — 可選本機或 Google 聊天模型（LLM_PROVIDER 切換；Gemini 需 langchain-google-genai）。
  • Chroma — 本機向量資料庫，持久化到 chroma_db/。
  • RAG — core/vector_store.py 檢索片段再組成回答上下文。
  • PyPDF（langchain-community）— 從 PDF 擷取文字供索引與抽樣。
  • python-dotenv — 在本機安全讀取 API 金鑰與模型設定。
  • Cursor — vibe coding 開發環境（邊聊邊改程式、快速迭代）。

目前進度

Phase 2 面具模式已可在本機端到端使用（streamlit run app.py）：學生首頁（app.py）精簡為戴面具 RAG 聊天與多面具切換；開發者頁（側欄「开发者 Developer」或首頁教師入口，以 DEV_PASSWORD 解鎖）負責上傳、索引、LLM 生成面具技能、畫廊與面具刪除。側欄預設開啟 Full file mode，並可將對話寫入本機 logs/*.jsonl（gitignore，不進倉庫）。倉庫內為虛構示範教材與合規說明；真實校內 PDF 應只留在本機。仍是教育／實驗用腳手架，非上線產品；公開 GitHub 連結之後會補在網站上。

這是一個大學課程的大數據分析項目，由我與另一位同學兩個人合力完成，並最終得到此課程所有組別中的最高分數。此項目通過分析 Spotify 全球 73 個國家的 170 萬行音樂數據，揭示音樂成功的關鍵因素。數據來源： Kaggle

第一部分：數據收集與準備

從 Kaggle 獲取 Spotify 每日更新的全球流行音樂 dataset，包含 25 列特徵和 170 萬行記錄。進行了數據清理、去重和特徵工程，為後續分析奠定基礎。

第二部分：分析方向

NLP 情感分析

（歌詞情感分析詞雲）

篩選熱門歌曲，使用 Genius API 獲取歌詞，應用 BERT 模型進行情感分析。發現具有明顯情感（高度正面或負面）的歌詞更易流行。

國家偏好分析

（對音樂響度的偏好）

（對音樂節奏感的偏好）

使用 Python 與 matplotlib、geopandas 繪製全球 loudness 與 tempo 偏好地圖，揭示地區文化差異與 danceability、energy 等特徵的綜合洞察。

機器學習建模

（簡單流程示意圖）

開發 XGBoost 分類模型預測歌曲能否進入熱門榜，依據 tempo、duration、key、valence 等音頻特徵，準確率達 72.56%，優於基準模型。

第三部分：項目總結

項目揭示情感張揚的歌詞、顯著的地區偏好差異，以及可用的熱門預測模型；並將洞察轉化為個性化推薦、本地化營銷與創作指導等商業價值。
